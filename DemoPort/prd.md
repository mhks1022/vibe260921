## 2. 목표 (Goals)

1. 방문자가 5초 이내에 "누구인지 / 무엇을 하는지"를 파악할 수 있도록 한다.
2. 대표 프로젝트(포트폴리오)를 클릭 몇 번 안에 확인할 수 있도록 한다.
3. 이메일 등 연락 채널로 자연스럽게 연결되도록 한다.
4. 모바일/데스크톱 모두에서 동일한 품질의 사용자 경험을 제공한다.

### 비목표 (Non-Goals)
- 회원가입/로그인 등 계정 시스템은 구현하지 않는다.
- 블로그 CMS, 댓글 시스템 등 콘텐츠 관리 기능은 1차 범위에서 제외한다.
- 다국어(i18n) 지원은 1차 범위에서 제외한다 (한국어 우선).

## 4. 정보 구조 (Sitemap)

단일 페이지(One-Page) 스크롤 구조를 기본으로 하며, 섹션 앵커(`#about`, `#skills` 등)로 내비게이션한다.

```
index.html
├── Header / Navigation (고정 상단바)
├── #hero        - 이름, 한 줄 소개, CTA 버튼
├── #about        - 자기소개, 개발 철학(바이브코딩 중심)
├── #skills       - 기술 스택 (바이브코딩 / Python / HTML5 등)
├── #projects      - 대표 프로젝트 카드 목록
├── #contact       - 연락처(이메일) 및 소셜 링크
└── Footer        - 저작권, 간단 링크
```

## 5. 기능 요구사항 (Functional Requirements)

### 5.1 Header / Navigation
- 로고 또는 이름(심규상) 표시, 클릭 시 최상단(#hero)으로 이동
- 섹션 바로가기 메뉴: 소개 / 기술 / 프로젝트 / 연락처
- 스크롤 시 헤더 고정(sticky), 모바일에서는 햄버거 메뉴로 축소

### 5.2 Hero 섹션
- 이름(심규상), 직함/한 줄 소개 (예: "바이브코딩으로 아이디어를 빠르게 현실로 만드는 개발자")
- "프로젝트 보기", "연락하기" CTA 버튼 2개
- 간단한 타이핑 애니메이션 또는 배경 그래픽(선택 사항)

### 5.3 About 섹션
- 개발자 소개 문구 (경력, 관심 분야, 바이브코딩에 대한 관점 등)
- 프로필 사진 또는 아바타 이미지 영역 (플레이스홀더 허용)

### 5.4 Skills 섹션
- 핵심 역량 3가지를 카드/아이콘 형태로 강조 표시
  1. 바이브코딩 (AI 페어 프로그래밍 / 빠른 프로토타이핑)
  2. Python (백엔드, 자동화, 데이터 처리 등)
  3. HTML5 (시맨틱 마크업, 반응형 웹, 웹 표준)
- 각 항목에 짧은 설명 텍스트 포함
- 숙련도를 시각적으로 표현(막대바, 별점, 퍼센트 등) — 선택 사항

### 5.5 Projects 섹션
- 프로젝트 카드 목록 (그리드 레이아웃)
- 카드 구성 요소: 썸네일 이미지, 프로젝트명, 한 줄 설명, 사용 기술 태그, 외부 링크(GitHub/데모 사이트)
- 초기 버전은 플레이스홀더 프로젝트 2~3개로 구성 가능 (추후 실제 프로젝트로 교체)

### 5.6 Contact 섹션
- 이메일 주소 표시: **mhks1022@gmail.com** (클릭 시 `mailto:` 링크 연결)
- 이메일 주소 클릭 시 클립보드 복사 버튼 제공 (선택 사항)
- 소셜/외부 링크 아이콘 영역 (GitHub 등, 추후 추가 가능하도록 구조만 마련)

### 5.7 Footer
- 저작권 문구 (예: `© 2026 심규상. All rights reserved.`)
- 맨 위로 이동 버튼

## 6. 비기능 요구사항 (Non-Functional Requirements)

| 구분 | 요구사항 |
|---|---|
| 반응형 디자인 | 모바일(360px~) / 태블릿 / 데스크톱 모두 레이아웃 깨짐 없이 대응 |
| 성능 | 정적 리소스 최소화, 이미지 최적화, 불필요한 외부 라이브러리 배제 |
| 접근성 | 시맨틱 태그 사용, 이미지 `alt` 속성, 키보드 내비게이션 가능한 포커스 스타일 |
| 브라우저 호환성 | 최신 Chrome / Edge / Safari / Firefox 지원 |
| 유지보수성 | 프로젝트/스킬 데이터는 마크업 내 별도 블록으로 분리하여 추후 교체 용이하게 구성 |

## 7. 기술 스택

- **마크업**: HTML5 (시맨틱 태그: `header`, `nav`, `main`, `section`, `footer` 등)
- **스타일**: CSS3 (Flexbox / Grid 레이아웃, CSS 변수로 테마 관리)
- **인터랙션**: Vanilla JavaScript (부드러운 스크롤, 모바일 메뉴 토글, 스크롤 애니메이션 등 최소한의 JS만 사용)
- **배포**: 정적 호스팅 (예: GitHub Pages 등) — 별도 서버/백엔드 불필요

> 개발자의 주력 분야(바이브코딩, Python, HTML5) 중 이 사이트 자체는 HTML5/CSS3/JS로 구현하며, Python은 추후 빌드 스크립트나 콘텐츠 생성 자동화(예: 프로젝트 데이터 생성)에 활용할 수 있다.
